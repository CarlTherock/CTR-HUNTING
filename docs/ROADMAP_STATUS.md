## Mesure de référence pour la phase 16

Build de production sous Node 24.21 : un seul fichier JavaScript principal de
**≈ 1,65 Mo (≈ 465 Ko compressé gzip)**, et Vite avertit d'un chunk de plus de
500 Ko. Aucune découpe par route n'a été faite. Ce n'est pas une mesure de temps
de chargement sur réseau mobile : celle-ci n'existe pas encore.
