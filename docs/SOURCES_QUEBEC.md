# Sources québécoises : couches, LiDAR, territoires

Dernière vérification : 2026-10-07. Méthode : les pages et services ont été lus
avec l'outil WebFetch / WebSearch (le shell du projet n'a pas accès au web hors
registres npm/GitHub). WebFetch **résume** les réponses et **tronque** les
documents longs : les noms de couches ci-dessous proviennent de lectures de
`GetCapabilities` / `?f=json` réels, mais **aucun rendu de tuile n'a été testé
dans un navigateur**.

## Ce qui n'est PAS vérifié (valable pour toutes les sources)

- **CORS** : « CORS non vérifié » pour tous les services. MapLibre charge les
  tuiles raster par `fetch` ; si un service n'envoie pas d'en-tête CORS, la
  couche échoue. L'application affiche alors l'état « Chargement impossible »
  (voir `rasterLayers.ts`) au lieu d'une carte vide.
- **Rendu réel des tuiles** (`export` ArcGIS avec `bboxSR=3857`, `GetMap` WMS
  en `EPSG:3857`) : construit selon les métadonnées (3857 listé par les WMS ;
  WKID 102100, alias de 3857, pour les MapServer), non testé en direct.
- **Légendes officielles** (images) : non vérifiées ; l'interface affiche une
  légende textuelle et renvoie à Forêt ouverte pour les couleurs.
- **Hors ligne** : aucune de ces couches n'est incluse dans le téléchargement de
  zone. Les licences CC-BY 4.0 autorisent la réutilisation des _données_
  téléchargeables, pas une mise en cache massive des tuiles d'un service
  public ; les conditions d'usage des services ne sont pas établies. L'interface
  l'indique. Aucun téléchargement massif n'est proposé.

couches de frontières affichent l'avertissement : « Une frontière ne prouve pas
un droit de chasse : l'accès, les saisons, l'espèce et les restrictions sont
distincts. »

au contrôle d'attribution de MapLibre (`attribution` de la source raster) et

`https://servicescarto.mrnf.gouv.qc.ca` a été ajouté (`build/csp.ts`, test
`src/app/csp.test.ts`) ; `geoegl.msp.gouv.qc.ca` et
`geo.environnement.gouv.qc.ca` y étaient déjà.
